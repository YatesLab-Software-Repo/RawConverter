# Parquet.Net

mzParquet output is written with Parquet.Net, which is built into the RawConverter executables together with the
libraries it uses. Each one's license is in this folder (it is copied next to the executables in builds):

| Package | Version | License | File | Source |
|---------|---------|---------|------|--------|
| Parquet.Net | 6.1.0 | MIT | `Parquet.Net.txt` | https://www.nuget.org/packages/Parquet.Net (Ivan Gavryliuk) |
| ZstdSharp.Port | 0.8.8 | MIT | `ZstdSharp.txt` | https://github.com/oleg-st/ZstdSharp |
| Snappier | 1.3.1 | BSD-3-Clause | `Snappier.txt` | https://github.com/brantburnett/Snappier |
| K4os.Compression.LZ4 | 1.3.8 | MIT | `K4os.Compression.LZ4.txt` | https://github.com/MiloszKrajewski/K4os.Compression.LZ4 |
| Microsoft.IO.RecyclableMemoryStream | 3.0.1 | MIT | `Microsoft.IO.RecyclableMemoryStream.txt` | https://github.com/Microsoft/Microsoft.IO.RecyclableMemoryStream |
| CommunityToolkit.HighPerformance | 8.4.2 | MIT | `CommunityToolkit.HighPerformance.txt` | https://github.com/CommunityToolkit/dotnet |

Parquet.Net's repository (github.com/aloneguid/parquet-dotnet) is no longer public; its license text is from a
copy of that repository and matches the package's MIT license and author.
